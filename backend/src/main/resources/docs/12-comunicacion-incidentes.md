# Comunicación durante incidentes

**Código:** SEC-GOV-012 · **Versión:** 1.6

Defina líder, relator y canales. Cada actualización debe incluir hora UTC, hechos confirmados, impacto conocido, acciones, riesgos, siguiente hito y responsables. Diferencie claramente hechos, hipótesis y decisiones.

Use canales aprobados y mínimo detalle sensible. No atribuya culpabilidad ni prometa plazos sin validación. Comunicaciones externas, regulatorias o a clientes requieren aprobación legal/comunicaciones. El informe final contiene cronología, causa, controles fallidos y acciones verificables.
