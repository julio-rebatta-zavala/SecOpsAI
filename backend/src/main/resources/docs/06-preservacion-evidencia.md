# Preservación y cadena de custodia

**Código:** SEC-DFIR-001 · **Versión:** 1.0

Toda evidencia debe tener identificador, origen, recolector, fecha UTC, método, hash SHA-256, ubicación y cada transferencia. Minimice cambios al origen, use herramientas validadas y copie de manera forense cuando corresponda.

Los logs exportados deben conservar zona horaria y fuente. Calcule hash al adquirir y al transferir. Restrinja acceso por necesidad y conserve registro inmutable. Si un dato contiene información personal, aplique clasificación, cifrado y retención aprobada. Nunca adjunte secretos activos a un ticket.
